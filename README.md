# 컨피던스스키 새 원페이지

이 폴더는 기존 배포본과 분리된 로컬 제작본입니다. `index.html`을 중심으로 메인, 코치, 프로그램, 가격, FAQ를 한 페이지에 구성했습니다. 현재 GitHub와 Vercel 배포본에는 반영하지 않았습니다.

## 로컬에서 보기

작업 중에는 `http://127.0.0.1:4182/`로 접속합니다. 미리보기 서버가 꺼진 뒤에는 상위 폴더에서 `node onepage-preview.cjs`를 실행하면 됩니다.

## 자료

- 사진·영상·로고: 기존 컨피던스스키 사이트에서 수집해 이전 제작본 `dist/assets`에 보관한 자산.
- 강사진, 4~18세 대상, 운영 장소, 수업 시간, 서울 셔틀, 카페 영상 피드백, 카카오톡 채널: 사용자 제공 자료와 이전 사이트에서 확인한 운영 정보.
- 가격: 공개 금액표가 없어 사용자 지시에 따라 상담으로 안내.

사이트를 배포할 때는 `canonical`, OG 주소, sitemap의 도메인을 실제 공개 주소와 일치시켜야 합니다.
